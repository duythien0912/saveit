# SaveIt

SaveIt is a private, on-device record of a person's everyday actions. It starts with one-tap logging and offers explicit Reminder creation after each Check-in.

## Language

**Action**:
A named everyday occurrence that a person may record, such as drinking water, taking medicine, going to bed, or waking up.
_Avoid_: Habit, task, routine

**Built-in Action**:
An Action supplied by SaveIt in a fixed starter set. The person uses these immediately and adds Personal Actions only when needed. The starter set is: Wake Up, Drink Water, Take Medicine, Breakfast, Go to Work, Lunch, Deep Breathing, Light Toileting, Toileting, Exercise, Return Home, Dinner, Shower, Brush Teeth, Relax, and Go to Bed.
_Avoid_: Action library, template

**Light Toileting**:
The neutral label for recording urination.
_Avoid_: Pee, urination

**Toileting**:
The neutral label for recording a bowel movement.
_Avoid_: Poop, defecation

**Check-in**:
A record that an Action happened at a specific time, created immediately with one tap. A Check-in has no duration; going to bed and waking up are separate Check-ins. Its recorded time may be corrected later from History.
_Avoid_: Completion, session, activity block

**Reminder**:
A notification schedule associated with an Action. After every Check-in, SaveIt offers—but never automatically creates—a Reminder using that Check-in's time; the person may edit it before saving. An Action may have any number of Reminders, including identical ones, and a new Reminder repeats daily by default.
_Avoid_: Alarm, automatic notification

**Reminder Check-in**:
A Check-in explicitly created when the person chooses **Done** on a Reminder notification. Receiving or dismissing the notification does not create a Check-in.
_Avoid_: Automatic completion

**Personal Action**:
An Action created by the person with a name, icon, and color.
_Avoid_: Custom item, custom activity

**Archived Action**:
An Action removed from the Today screen. Its Check-ins remain in History, while all of its Reminders are removed.
_Avoid_: Deleted Action
